# 问题专案：kit.gd 装载行拼接事故（m74 发现，m69 引入，2026-11-16）

## 现象
m74 做角色流程时 flow_probe 报"官方事件不足 2 个"——顺藤 kit_smoke 也红（`官方事件装载 demo_youshio1=无`）。**自 m69 起无人跑过 kit_smoke**，回归静默潜伏 5 轮。

## 根因
m69 用 python 拼接把 `func _load_deployed_cfg()` 插到 `_ready` 内部的 `DirAccess.make_dir_recursive...` 行**之前**——该行及其后的 `_load_official()/_load_official_timelines()` 原是 `_ready` 的运行时后半段，被并进新函数体成为其尾部语句（语法合法、零报错）→ `_ready` 在编辑器门 return 后即结束，**装载从未执行**：
- GameKit 纯运行时（标题→试炼场/kit_smoke）：officials=0 静默断电
- th75 宿主：走自家 GameGlobals 装载，幸免
- 编辑器：走自身 `_load_official_csv`，幸免
- 唯一能抓到的门禁 kit_smoke 自 m69 起没进轮末清单=漏网

## 修复（GameKit=70db188）
装载行归位 `_ready`（editor-gate return 之后）+ `_load_deployed_cfg` 尾部清除被吞行。KIT_OK 恢复。

## 验证
GameKit：KIT_OK+FLOW_OK+SCN_OK+THXP_OK+exit_probe exit0；th75：SPELL_OK+PERF 3.84ms/583弹。

## 教训（两条入铁律）
1. **python 拼接插函数体的锚点，禁止选在另一函数内部的目标行**——插完必须目检目标函数边界（func 头到下一个 func 头的完整阅读）。
2. **内核 kit.gd（autoload）改动必跑 kit_smoke**——它是不受宿主/编辑器双幸免层掩护的唯一纯运行时门禁；同理 submodule 同步后必须 `git log` 核对 HEAD 真的到达目标（本轮 pull 曾被 untracked .uid 阻断而 `| tail -1` 掩盖了失败）。
