# 性能专案：1400+弹滞留与渲染侧填充率炸点（m82，2026-11-17）

## 现象（作者双口径已确认——裸跑+调试同现）
同样角色列表对战，历史经验"弹幕顶多闪一两次 1000"，实测**持续 1400+弹**、fps 6-22、proc 尖峰 15-54ms、phys 均值 14ms。618 弹=60 帧+（健康侧）。

## 根因分析（自查回忆+数据佐证）
### 主根因：消弹断供（m79 引入，m82 修复）
时间线：m76 前每次释放能力/符卡**必定挂载** svgresign+clean（消弹圆+每事件帧消弹）→m79 按裁定删古典默认（符卡定义为唯一来源）→**角色们尚无 spell.csv 定义→释放后零消弹→弹幕只出不清→持续累积**。
佐证：作者观测峰值段"无符卡消弹"（完全吻合）；"闪一两次 1000"的历史记忆=有消弹时的峰值形态。
**修复（m82）=回退式挂载**：有 spell.csv 定义→严格按定义（裁定保留）；无定义→回退古典 svgresign+clean（消弹不断供）。

### 次根因：30Hz 持续域撤除（m77，双保险的第二根）
m77 撤 30Hz 域（当时与古典流程并存=双保险），m79 删古典流程后消弹彻底无路径。clean 10Hz 单轨在**有载体**时工作正常（618 弹 60 帧）。

### 渲染侧（与滞留独立的第二问题）
1400+弹时填充率爆炸：1000+ 半透明弹×窗口放大系数；GPU A/B 判决 DDM/热力管线无罪。
**LOD（m82 落地，作者定义=材质原始尺寸分级驱动绘制尺寸）**：LOD_DRAW_CAPS 表（≤32 不封顶/64→64/128→128/256→192/>256→256 绘制直径上限），主流 16×16 小弹零影响；开发者建议=减少大图弹幕素材引用（策划案纹理规格：2 的整数次方正方形或单像素宽）。

### 被否决项（作者 20261117，存档备查）
- ❌ **MM 纹理图集整合**：原理=多纹理各一个 MultiMesh 实例流（draw call=纹理种数），图集合并减切换。否决理由：实测 3.5ms 是 CPU 组装侧非切换侧、纹理种数不多收益有限、图集管理复杂度不值。
- ❌ **渲染缩放系数下调**：原理=整体画布降采样再放大（像素数减少=填充率等比省）。否决理由：全画面变糊，与精确像素美学冲突。
**两者如未来重启，需先重测当时口径**。

## 豆包审计建议关注点（作者带数据去找时）
1. `battle_arena._spell_timeline_run`（挂载条件/sp==null 分支）
2. `_apply_clean`/`_clear_bullets_around` 调用链与频点（10Hz 事件帧）
3. 激光 oob 豁免（bullet_runtime.update 非激光才销毁——激光只靠 range）
4. `until_frame` 生命周期（m-spell 消弹期）
5. `draw_bullet_mm`/`draw_entities` 每帧成本结构（3.5ms/1.1ms 常驻）

## 教训
1. **删除默认行为前必须确认数据面已覆盖**——"定义驱动"的前提是定义存在；m79 删古典默认时角色们 spell.csv 全空=断供。
2. 消弹路径改动后，弹数轨迹（TELEM）应作为回归门禁（本专案后 TELEM 已含于 battle_tick_perf）。

# m83 追记：豆包审计修正与修复落地（2026-11-17）

## 审计对本文的修正（成立，照录）
1. **时序**：07:09 数据早于 m78/m79/m82 提交——不能用来证明"m79 断供"；数据中 clean 在跑（194/770 帧非零）。
2. **弹数=振荡非堆积**：630→1213→274→883 反复回落；只出不清应单调顶到 MAX_BULLETS=8000。真实现象=**峰值期清不赢**。
3. **m79 保留分支**：无时间轴角色一直有 clean；被删的只是"有时间轴但无定义"一支（m82 回退挂载修复的正是这一支——修复本身仍有效，归因范围收窄）。
4. **投放侧乘子（作者 tick 判断的方向佐证）**：m75 后释放=时间轴逐 tick 投放+旋转展开+载体死亡炮节点续发——生成侧净增，与 spell 定义无关。
5. **探针口径残**：hd_side 已废字段报错（A/B 半途中断）+物理双跑+headless 无渲染——原 GPU A/B 结论作废。

## m83 修复落地（四项）
1. **MM 容量分块增长**（超线性元凶）：256 一档取整扩容——上升段缓冲重建从 O(n) 降到 O(n/256)。真窗口默认队 fps 60 全线（修复前同场景 17-37）。
2. **render_color_alpha 静态路径零分配**：复用数组实例（原每弹每帧一次 Array 分配）。
3. **repeat 初始化 fastpath**（作者"明确不启用的直接略走"首批）：repeat_time=0 → repeat_enabled=false（原恒 true=每弹每帧空查）。
4. **探针修复**：hd_side 撤/物理双跑撤/census（可见/场外分组）进 TELEM/consts 回清洁默认（STRESS=false、DISABLE_GPU=false）；编辑器 `--probe` 启动符直接展开探针页（探针页=懒建+手动刷新，本就无自动加载）。
