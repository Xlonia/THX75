# 0.0.9 对战存档第一片：阵容+对战逻辑（m101，2026-11-20）

## 作者定义（本片范围裁定）
「存档模拟和测试，继承的是修改角色组能力因素（弹幕伤害倍乘、弹幕速度、技能、角色逻辑等）。现在的版本只做：**角色阵容和对战逻辑保存为存档，以及读取存档里的这些内容**。」

对应 scheme 345-353「对战存档与存档编辑器」——本片交付其中两行：队伍角色（阵容）+角色对战逻辑；其余内容（队伍事件/可召唤角色/道具/键位与机控预设）留后续片。

## 现状盘点（实现前）
- 阵容=`GameGlobals.versus_player_team`/`versus_enemy_team`（选人界面→_on_start 写入→arena _setup_versus 消费）；
- 对战逻辑=`GameGlobals.versus_chara_cfg[cname]`：logics（三步向导列表：stance/stance_dist/metric/aim/volley/cruise/appeal_boost/avoid_phys_pair）+formation（杂兵排布）+pp/spell（资源）；
- **伤害倍乘/弹幕速度/技能=当前版本尚无可改状态**——存档格式直接整体带 versus_chara_cfg，后续批次这些因素进 cfg 即自动随档（格式不用改）。

## 实装
### GameGlobals（三接口）
- `save_battle_save(fname, player_team, enemy_team)` → `user://battlesaves/<名>.thxb`；JSON 明文（存档编辑器后续直接改它）：`{kind:"thx_battle_save_v1", version:1, saved_at, player_team[], enemy_team[], chara_cfg{}}`；
- `load_battle_save(fname)` → 校验（存在/JSON 可析/kind/结构）**全过才应用**——整体替换 versus_player_team/enemy_team/versus_chara_cfg（斗蛐蛐复现口径：档内是什么就是什么），坏档不半改现状；文件名无后缀自动补 .thxb；
- `list_battle_saves()` → [{name,path,mtime}] 按修改时间新→旧。

### versus_menu（两按钮，按钮两列网格）
- **保存**：FileDialog（ACCESS_FILESYSTEM，目录 globalize(battlesaves)，默认名 `对决_20261120_HHMMSS.thxb`，过滤 *.thxb）→ GameGlobals.save_battle_save → print 结果；
- **读取**：列表对话框（ItemList+阵容摘要行：我方[]敌方[] 配置N项·逻辑M条 / 刷新 / 读取并应用 / 删除两次点击确认）→ 应用后 `_set_team` 回填选人界面+贴图逐槽刷新（可继续微调后开始决斗）。

## 验证
- BSAVE_OK：round-trip 逐项一致（阵容含留空槽/logics 两条含 desc·volley 字段/formation/pp/spell）；无后缀名读取；坏档四拒绝（非 JSON/kind 不符/结构缺项/档不存在）且**不半改现状**；列表枚举；探针档自清理（不污染作者 user://）；
- 回归：MENU_SMOKE_OK（读取对话框改动后菜单构建无损）+SMOKE/SPECIAL/SPCLASS/SPELL/CLIP/SUPPRESS/RING/VANGUARD/EMERGE/KIT/mm_layout 全绿。
- 过程小坑：`_refresh_pick_tex(side, i)` 双参签名记错（单参调用=Parse Error 菜单构建失败——冒烟探针当场拦住，改逐槽刷新循环）。

## 遗留
- 对战存档其余内容（队伍事件/可召唤角色/道具/键位与机控预设）=后续片；
- 能力因素（伤害倍乘/弹幕速度/技能）尚无修改入口——进 versus_chara_cfg 后自动随档；
- 存档编辑器（复制剧情存档改数据作用于自定义对战）=后续片，JSON 明文已预留可编辑性。
