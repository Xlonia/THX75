# 片段化第二批：编辑器片段页+存取链（m86，2026-11-17）

## 任务理解
作者令：片段化只做一半无法测验——继续下一批。作者另两条裁定：①消弹 10/30Hz 之问=愚蠢问题不再提（本就没有消弹时频率无意义）②弹幕数量问题找不到理由就算了，当已解决。**两条已入记忆封存。**

## 实装（两步流全通：弹幕→片段→角色）
1. **编辑器「片段」页**（tab 条新增，弹幕/角色/杂兵/时间轴/符卡/**片段**/排布）：
   - 列表+新建/删除（工作集自建 clip_1 兜底）；
   - 详情：名 LineEdit + **最低长度** SpinBox（0.1s，≥1）+ Flash 式 tick 帧格条（格内数字=该 tick 事件数，tooltip 全事件名）+选中 tick 安放/移除/清空（事件下拉=弹幕页工作集）。
2. **包存取**：`danmaku_clip.csv` 随 .thxp/.thx/.thxe 保存；`_load_package` 恢复（清空重入）；**顺带修复存量缺口——spell.csv m78 起保存了但装载从未恢复**（探针播种验证 1/1 恢复）。
3. **导出为官方数据**：片段随落盘（与官方事件表同目录=danmaku_clip.csv，部署侧 battle_arena._ready 并入），写入即并入注册表（运行时无需重启）。
4. **角色页槽位选段器**：main/sub/rest 挂载下拉=**片段优先**（工作集+注册表去重，显示"片段 xxx"）+弹幕直引仍可选（"弹幕 xxx"，旧数据兼容）；绑定行标签识别片段（`[片段 Ntick]`）。
5. **工作集链**：kit.gd `editor_clips`+兼容层 shim（GameKit 独立编辑器）+th75 宿主 `GameGlobals.editor_clips`；解析序=**工作集>注册表**（resolve_clip/两槽位函数统一 `_resolve_clip_ref`/`_resolve_clip_any`）——试炼场实时改片段立即生效。
6. **ClipData 编辑助手**：add_event/set_events/events_at/save_csv（与 TimelineData 同构）。

- EDT_OK 扩断言：片段页构建（工作集 1 片段）+包往返恢复（片段 1/符卡 1）。
- CLIPED_OK（内核 --script 态：往返/工作集优先/条目混合 n=3）。

1. 双仓 pull → 打开编辑器 → 「片段」页 → 新建片段 → 帧格条选 tick0 → 安放一个弹幕事件 →（可选再放 tick3 做片段内延时）；
