# 环规格双修 + 命题B 普查（m99，2026-11-20）

## 作者实测反馈
1. **判定圆出现但没以前明显** + **消弹圈粗成圆环不是原汁原味**——统一 15px 源描边顾此失彼：判定圈（r10→1.17px 可见）保住了，但消弹圈（r80-200→11.7px）粗成了"环带"。

## 修复：分规格烘焙（m99）
- **细环**（15px 源描边）：判定圈/自机小圈/结界圈——小半径下屏上 0.7-1.6px 可见；
- **原味环**（2px 源描边）：消弹圈——大半径下与旧 draw_arc 同粗细（r100≈1.5px 屏上）；
- `_draw_ring` 加 spec 参数（1=细环/2=原味环），烘焙键=段数×10+规格。ring_probe 回归 10502px。

## 命题B 普查（作者令"本轮同时做完"）
**接管面实测**（mh_eligible_probe，922 弹真实场面）：
- **C++ MotionHot 已接管 843/922（91%）**；
- GD 逐帧仅 71 弹：**repeat 载体 67**（eligible 排除 repeat 保留 GD 节拍）+ other 4；
- `_bullet_updates` 内部分账：cpp 哈希插入 1.20ms + GD 逐弹 update 0.30ms + 循环分支 0.19ms + MH 回填 0.01ms ≈ 1.7ms；剩余 ~3.4ms = repeat_tick 921 次/帧方法调用 + cpp advance + sync_shared。

**结论：命题 B（GD 逐弹 C++ 化）边际小**——GD 逐帧弹只剩 71 个（0.3ms），C++ 化收益≤0.3ms。真正剩余可压：
1. cpp 哈希插入 1.2ms（并入 C++ advance 循环）；
2. repeat_tick 921 次/帧方法调用（载体标记轮桶化）；
两项合计 1-1.5ms，属 0.2.0 BulletSystem C++ 全量化范围。
