# v0.0.8 第三批（2026-10-26）：满天星根因修复 + 判定弧演绎 + HUD 字幕

## 一、判定弧的演绎（作者问：弧形来源与判定流程）

**弧的来源**：所谓"判定弧"不是一个新几何体——它就是**态势十六点的 1d 环本身**（角色 0.1 秒距圆周上的 16 个采样点，带转偏移与 AI 采样同源）。方案2 的"巡航判定弧"＝把巡航快机里"方向弧上连续点重合检测"的思路复用到 APF：16 个点**首尾相连成环**，做连续段扫描。

**判定流程**（`_ai_drive` 内，每物理帧）：
1. 逐点扫 1d 环（16 点热度 >96 计为"热"）；记录最长连续热段长度与起点 k；
2. **环绕拼接**：若序列尾部与首部连续（如 15,0,1,2 连续），拼成跨零点段——这就是 C 形环绕的检测关键（C 形缺口两端在环上首尾相接）；
3. 连续热段 ≥4 → 判定"墙"：记 `apf_wall_k`（墙起点方向）→ **墙法向外推 0.5**（离墙分量）＋ APF 热点斥力弃权 → 交给 RET-C 树找开口（树按低热方向评估，C 形开口=环上冷段=树的自然出口）；
4. 平行弹幕横断场景：横断墙在 1d 环上成连续热段 → 同样触发；角色的"跨越"冲动（引力直穿）被墙法向抵消。

**与巡航判定弧的关系**：巡航（快机）检测的是"方向弧上有弹幕→停快机"（防撞）；APF 接管检测的是"1d 环连贯覆盖→弃权采样斥力"（防采样盲区）——同一个环、两种消费，均纯 CPU 查表。

## 二、"满天星"热力图根因与修复（系统性，非数据问题）

**根因**：DDM 是**逐帧重建的瞬时快照**，Ht 加热**每 0.1s 才读一次**——速度 v 的弹幕两次采样间移动 6v 像素（v=2 → 12px），而热力图扩散半径只有 1px——加热点之间留下 12px 空档 → 热力轨迹=间隔点列 → 远看"满天星"，无论平行还是扇形弹幕都不成形。角色摇摆的原因：环采样点恰好落在点列上时值高、下一拍落空 → APF 方向逐拍翻转。

**修复（扫过段盖章）**：每个弹幕追踪 `heat_prev`（上次采样帧位置）；**采样帧（time_frames%6==0）**的 DDM 印章从"当前位置一个圆"变为"heat_prev→当前位置的沿线段"（步长=弹半径）——热力轨迹连续成线（平行弹=梳子/栅格，扇形=连续弧）。非采样帧行为不变（DDM 60Hz 快照语义保持）。

## 三、HUD 字幕（作者要求）

# v0.0.8 第五批（2026-10-26d）：分身八点 + RET-SP 完整两步树

## 分身八点（L42/L227·作者指出的 RET 基底弱项）

原实现把未来分身当**判定点 0 的理想化自己**——胖判定（Determine+Defend 大）角色会"自认为正确地碰到弹幕"。落地：
- `avatar_ok(pos)`：以角色**结界圆半径**（barrier_radius=Determine+Defend）八等分的 8 个圆上点，逐点 `bullet_hit_query`（真实弹幕碰撞，无近似）——任一点与敌弹重叠 → 该假设位置不可行。
- **RET-C 终筛**：1d/2d 引力点候选（前 3）须分身可行（L230：1d/2d 查分身、5d 仅点位置）。**性能分频**：原逐环点全查=每拍 1280 次 hash 查询（实测把物理打到 33ms 均值），改为只查最终 3 候选（÷10）。
- **RET-SP 两步树内**：第一/第二步假设位置均过 `avatar_ok`。

## RET-SP 完整两步树（L228-234·替换简化版）

- **第一步**：1d 环 16 方向（Hcs<64 + Ht<96 + 分身八点）；
- **第二步**：假设到达该 1d 点后的 16 方向（2d 环 Hcs/Ht 代理 + 分身；**4 方向抽样**（45°间隔）性能分频——代表可行即其 4 个第二方向可行）；
- **Sl**=Σ 可行第一方向的第二步可行数（0~256）；全堵 Sl=0 → e 态势（战场既有链路消费）；
- **引力场数轴**（L228）：方向在 ret_gravity 轴负分量侧 → 倾向 −4；
- **AI 接管**（d/h/e 防御态势）：倾向最高的第一步方向与 APF 合成（树 1.2 / APF 0.4）。
- **近似声明**：Hcs 只有三环固定点——"假设位置的 Hcs"用 2d 环值代理（完整版需假设位置平移重采样，逐点 Hcs 重算成本高，列入观察）；分身八点为真实查询无近似。

## 验证

RET_OK 12 断言（分身八点定点正反例/全冷 Sl=256/全热 Sl=0/共存）、SMOKE_OK 112、WALL_OK、E2E 全绿、战场零解析错。物理 14.18ms 中位/21.27ms 均（分频后较 33.65ms 均值回落；作者高载数据持续超 10ms 线——**22b 分频优化为 0.0.8 收官首项**）。快照 `*_修改后20261026d.gd`。

1. RET-SP 第二步分身 4 方向抽样（45°间隔）是性能折衷——若您要求 8 点全查， physics 预算需要先做弹幕主循环分频（22b），示下优先级。
