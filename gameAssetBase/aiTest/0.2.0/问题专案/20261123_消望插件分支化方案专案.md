## 2. 方案列表（逐项批复）

### P1 插件入 kit 仓（核心动作）

- **迁移**：`keshinozo/` → `kit/addons/keshinozo/`（与内核 `kit/addons/thx_gamekit/` 平级）。
- 效果：kit 仓 = 内核 + 全部插件源码（作者目标落地）；kit standalone 编辑器项目天然自带玩法源码，打开即可调试。
- th75 侧：主仓删除 `addons/thxgamekit/keshinozo/`（文件移入 submodule，主仓记录删除）。
- **游戏数据不动**：`gameAssetBase/`、`Characters.csv`、`danmaku_event*.csv`、`spell.csv`、`timelines/` 等全部留在宿主原位。

### P2 插件元数据（plugin.cfg / plugin.gd）

- 新增 `kit/addons/keshinozo/plugin.cfg`（name=keshinozo）+ 最小 `plugin.gd`（extends EditorPlugin，无编辑器逻辑）。
- 效果：编辑器插件列表可独立启停消望插件。

### P3 引用路径更新（4 处 + kit 侧 2 处）

- th75 `project.godot`：
  - `GameGlobals` autoload → `res://addons/thxgamekit/kit/addons/keshinozo/game_globals.gd`；
  - `[editor_plugins] enabled` 追加 keshinozo plugin.cfg。
- 3 个场景 ext_resource 路径（battle_arena.tscn / title_menu.tscn / versus_menu.tscn）。
- kit `project.godot`（standalone 编辑器项目）：autoload `GameGlobals` 指向插件内路径 + enabled 加 keshinozo——**kit 编辑器自带玩法可跑**（见批复点②）。

### P4 文件格式改进（设计呈报，批准后另行实施）

- **.thx 内容包加可选 `manifest.json`**：`{"format": 2, "plugins": ["keshinozo"], "domains": {"arrange": "keshinozo", ...}}`——声明包依赖的插件与文件夹归属域。<u>//批准</u>
- kit.gd 开**内容域注册 API**：插件启动时声明自己提供的内容域；包加载遇未知域=警告列出、不炸（多插件共存向前兼容）。<u>//批准</u>
- manifest 纳入现有**签名强校验**覆盖范围（防篡改链不变）。<u>//插件导入时也可加入强校验</u>
- **二进制导出约定**（文档化进 kit README）：主体导出排除各插件目录；每插件单独导出（Godot 导出预设按目录排除/附加即可）。<u>//批准</u>

### P5 音频归属

- `music/` **留在 th75**（宿主附加音乐目录——ChapterFlow.music_search 本就是宿主注入设计），**不入 kit 公开仓**（自制曲 MIT 许可未开）。
