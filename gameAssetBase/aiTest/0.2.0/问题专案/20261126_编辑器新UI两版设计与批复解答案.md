## 2. 五区壳（所有工作区共用骨架，1280×800 基准）

```
┌──────────────────────────────────────────────────────────┐

│   ｜ [角色: MarisaA ▾] [弹幕: 弹幕A ▾]（切换按钮——批复①）   │

├────────┬──────────────────────────────────┬──────────────┤
│ 左坞    │ 中央主编辑区（随工作区切换）        │ 右坞检查器     │

├────────┴──────────────────────────────────┴──────────────┤
│ 底坞 232px：预览（角色/弹幕页）或 时间轴（剪辑页）——对换批复  │
├──────────────────────────────────────────────────────────┤

└──────────────────────────────────────────────────────────┘
```

**壳级交互（批复原文）**：
- 顶栏切换按钮：点击/悬停呼出面板（角色列表卡+「＋新建角色」+「双击=调整原版角色」）——**左侧不再放常驻选人面板**
- 操作指引：**不塞教程**；双击 `/` 键呼出可关闭介绍窗口；输入时不感知双击
- 素材库交互：右键=通用资源操作（复制/剪切/定向打开）；**双击=预览+引用者反查**；**拖到输入框=直接引用**（剪辑素材拖放除外）
- 可行性检查：顶栏常驻；通过=绿；**立即保存测试副本→预览立见新弹幕**

## 3. 左坞素材库（全部工作区共用）

**类别标签页**（批复④）：`纹理｜音效｜弹幕｜片段｜符卡｜角色` 六标签，选中红底白字；标签页下收纳各自可展开树（如 纹理→danmaku/anime/character 子目录）。搜索框置顶。底部提示"拖拽素材 → 编辑区/时间轴"。

## 4. 六工作区布局（v2 定稿态）

### 4.1 角色工作区（v2 板01）
- **中央=火力点配置图**（扩大——角色列表已撤至顶栏）：画布内角色剪影+结界圈（青虚线椭圆）+判定点（白圈）+五火力点（主机金/僚机青圆点+标签"主机首要 wpcs0"等）；z=预览该火力点；拖拽火力点写回排布（七项可表达式）
- **右坞四标签**（v1 承接）：角色元数据｜角色表现｜角色性格｜角色弹幕；字段行=label+值框；表达式字段带 `ƒx` 两小按钮；占比>1 → **金色警示框"像输错密码一样提示，禁止应用"**；☑魔弹☐物弹（消望语义=插件域标注）
- 底坞=弹幕显示预览（同弹幕页，见 4.3 底坞条目）

### 4.2 剪辑工作区（v2 板02——预览对换批复）
- **中央=预览画布**（接近正方形稍扁——批复理由：画布尺寸如此）：章节演练画面+**缩放控件（－/100%/＋/适应）**+**右下角播放操作组（▶ 播放 · Z 循环 · ‹ , › 帧步进）**
- **底坞=总剪辑时间轴**（宽扁 1280×232）：五轨=角色轨（含**附属弹幕片段子条**——批复②"没必要多一个弹幕轨"）/音乐轨（A,B 拖柄 DAW 式）/背景轨（ogv）/触发器轨；时间刻度事件帧=10；**播放头红竖线+倒三角**
- **标签旗楔形图章**：瞬时事件（触发器/关键帧/切换/休止符）=竖杆+45°三角旗+底横杠（紫系）；**省略号折叠+悬停展开+图层层级暂时最高**（批复原文）
- **封顶勘误（批复②）**：SpinBox 256 封顶**仅弹幕片段**；章节/总剪辑不封顶
- 工具条：✂切片 ⧉复制 🗑删除 🧲吸附 ＋轨道；拖动=移动/拖+Ctrl=复制/边缘拖=切片/吸附到帧
- **右坞三标签**（批复③）：片段属性｜运动走向｜触发器——**各自独立标签页**；触发器=**可折叠列表（▾/▸）+＋添加+−删除**，两段式=条件紫框+执行绿框
- 运动走向标签页：贝塞尔关键帧菱形金手柄可拖+规定关键帧序列

### 4.3 弹幕工作区（v2 板03——预览对换批复）
- **中央=弹幕显示预览**（画布 400×400 适配、接近正方形稍扁）：弹幕点+rotate_range 扇形示意+缩放控件+**右下角播放操作组（批复③）**
- **底坞=参数配置**（宽扁）：四标签=**通用参数｜弹幕表达｜使用者｜颜色**（批复：颜色并入标签页）；通用参数两列表单；折叠组（旋转散布组/高级——渐进披露）；行进类型切换金色警示（独有参数将被清除需确认）；使用者反向查询行；禁 `#` 提示
- **表达式输入框=底坞右侧**（批复②）：语法高亮/括号配对/内联波浪线报错/Ctrl+Space 补全
- **弹幕事件切换=顶栏菜单**（同角色；下拉处显示**引用材质**——批复）
- **右坞=色板（Krita 式，m127 批复）**：密集网格（12 列）+选中行（色样+名称下拉）+「新色板」+底部工具条（▣色板 ＋创建 ✎修改 ▦网格 🗑删除）——**创建/删除色块、修改=画图调色窗**
- **画图调色窗浮窗**（修改态）：大饱和度亮度区+十字准星+色相竖条+颜色/纯色双预览+RGB/色调/饱和度/亮度输入+hex+添加到自定义颜色+确定/取消——**OS 画图同款**（批复：成熟范式直接用）
- **B 面浮窗**（原批复复刻）：RGB 三渐变条（拖柄+数值）+color_ab 表达式框；**A/B 切换按钮在标签页右上角**（面板态）/浮窗右上角（弹窗态）；非法值兜底另一色；与色板联运（色板选色=A 面/✎=调色窗/B 面按钮=本浮窗）
