# "x_copy 与 x 相同"真因：整扇目标不共享 报告（2026-10-25 第八批）

**作者反馈**：x_copy/y_copy 表现完全与 x/y 相同；已在自定义对战把 demo_aimed 配给铃仙、demo_youshio1 配给晚汐供探针测试。语义重申=20261025b 定义（x_copy=R(−a)·(x,y)，模长不变）。

## 真因（自定义对战真实链路探针铁证）

盖章数学本身**一直是对的**（四角度对照 R(−a)·(100,−200) 全 OK）。问题在**上游**：敌方队有晚汐+5 个私兵（FairyA/B/C、ElfA/B），而**每个副本在各自 setup 时刻各自调 `bullet_nearest_enemy`**——从各自位置选到**不同的敌方成员**（有的选晚汐、有的选 FairyA、有的选 ElfB）→ 每副本 target_x/y 各不相同（实测 tx=+229/+202/+176/+156/+140/+136 六个值）→ x_copy 跟着各异 → 整扇看起来"和 x 的自机狙分散一样"，永远不汇聚。

**这正是"副本发射后决定"语义的缺失一环**：目标快照应该**整扇一次决定、全体共享**，而不是逐副本各自决定。

## 修复：整扇共享目标快照（发射时刻一次决定）

- `_spawn_event_copies` 入口解算**一次**共享目标（`bullet_nearest_enemy_from`）+ **一次**目标相对快照 `shared_txy`（相对发射原点；绝对坐标事件取绝对位）——传给全部副本（含延时队列 `_pend`、repeat 整扇重放代）。
- `Bullet.setup` 增 `shared_target/shared_txy` 参数（成员暂存供 `_fill_position_vars` 使用）；`shared_txy` 有效时 target_x/y **直接采用入口快照**（不再各自重选/各自相对）。
- repeat 整扇重放传入载体自身的 target 快照（重放代继承载体的目标基准）。
