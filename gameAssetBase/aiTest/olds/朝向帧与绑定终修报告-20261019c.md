## 一、绑定仍不可见的真正根因（第二层）

上批修了"编辑器数组与 GameGlobals 不同步"，但还有第二层：`get_slot_events` **只在 `arena_mode=="preview"` 时才读编辑器工作集**——自定义对战（非 preview）只读官方/Mod CSV。所以绑定数据活着、却永远到不了火力点；编辑器"使用者"页同函数查询（非 preview 模式）→ 显示"无任何角色使用"。

**修复**：编辑器工作集**恒定**并入槽位查询（最高优先、按事件名去重）→ Mod → 官方。smoke 实证绑定可见。现在的数据流：编辑器内绑定即时生效于自定义对战（无需导出）；导出官方 CSV 后为持久数据。

## 二、角色朝向帧（批复：火力点/杂兵/贴图以朝向为 y 轴）

- `BattleEntity.facing`：默认按阵营对峙（我方右/敌方左），**移动即转向**（暂与速度方向一致，未来 AI 拓展再细分——按作者说明）。帧向量助手：`frame_forward()`=朝向（局部 y）、`frame_right()`=朝向顺时针 90°（局部 x）、`frame_back()`=-朝向；`frame_to_world/world_to_frame` 局部⇄世界。
- **火力点 poi 帧重建**（fire_control）：主要火力点=朝向前方 0.1 秒距（main_y 沿朝向）；僚机=朝向垂直**两侧** 0.2 秒距（sub_x 正=远离角色）；poi 步进 x=该侧朝向（主点=lr×right、僚机点=sub_lr×right）、y=角色背向。旧实现把僚机排在世界 x 轴、背向取世界 y——正是作者指出的三者错位。smoke 实证：facing=RIGHT 时僚机在 (0,±22)、转向 UP 后编队随帧旋转到 (±22,0)。
- **杂兵**：`local_pos` 改为角色局部帧坐标（x=右,y=前）；AI 世界方向位移经 `world_to_frame` 入帧，`sync_private_pos` 出帧——角色转向时整个编队随帧旋转（"角色怎么动它们也跟着动"的完整语义）。排布预设公式本就是局部帧（termin_point x=散布,y=前后），无需改。
- **贴图**：实体绘制加**前向刻线**可视（贴图实装时旋转角=facing.angle()+π/2，纹理上方对朝向——已在代码注释留档）。

## 三、t / t_copy 语义（按批复重做）

- `t`=**弹幕事件的已存续时间**：首发 0；repeat 重放子代=载体释放时刻的 t；rotate 延时副本=基时+步进延时。链路全程透传（`_spawn_bullet` 增 event_t；`_rot_pend` 带 et）。
- `t_copy`=**本副本已存续时间**（=原内部 t，运动/航程/repeat 节拍继续用它——行为不变）。
- ctx 映射：`t = t_event + t`、`t_copy = t`。smoke 实证子代 t=31/t_copy=0。
- roll 类在 rotate 参数中无语义（批复确认）——rotate 求值上下文中保持 0，不做处理。

## 四、量纲迁移（类型一览.csv 对齐）+ 本轮更新两项

| 项 | 迁移 |
|---|---|
| saturation | 0~1 → **0~256 整数**；渲染 S=value/256；默认 0（=不上色的灰白材质，符合黑白材质上色哲学） |
| hue | 0~1 绝对 → **-256~256 相对 color 基础色相的偏移**；H=fposmod(base_hue+hue/256,1)；base_hue 解析 color 列（高级 RGB 拆解优先） |
| alarm_shader_alpha | 0~1 → **0~256 整数**；预警期比值=value/256；解析缺省 256（保持现行为——CSV 默认 0 会让无值行预警隐形，偏差已列） |
| alarm 表达式化 | `alarm_s` 算式列（整式）；出生时求值入 `alarm_now`（被弹/预警渲染/t_r 全改读个体值） |
| color 高级 | 表尾追加 `color_r/g/b` 三列（0~256 整式）；编辑器颜色行+「高级」按钮展开 RGB 三行（默认折叠）；非空时覆盖 color 列参与 base_hue 计算 |
| 数据迁移 | 五份 danmaku_event_*.csv：saturation/hue/alarm_shader_alpha 数值 ≤1 的 ×256 取整；表头补三列（修改前副本已存 aiTest） |

其余核对：alpha 本就 256 制 ✓；lost 系/speed_max/turn_arg 等数值口径无冲突；x_offset/y_offset/dmg/repeat 系上批已整式化 ✓。
