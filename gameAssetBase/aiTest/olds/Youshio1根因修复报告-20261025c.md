# Youshio1 静止根因修复报告（2026-10-25 第三批）

**作者反馈**：x_copy/y_copy 问题依然存在，Youshio1 表现与修改前完全相同。

## 根因（铁证复现）

**gettarget 的参数正则 `[a-z]+` 匹配不了下划线**——`gettarget(x_copy)` 整个调用**不被翻译**、原样残留进表达式；Godot Expression 在**解析期不检查未知函数**（编译"成功"），到**执行期才静默失败**回退 0。于是 Youshio1 的 x/y 恒为 0 → 速度恒 (0,0) → **16 发弹幕全程静止在出生点直到航程到期**——修复前后一模一样（作者所见完全一致）。我上一批的正式测试用的是裸 `x_copy/d` 写法（能翻译），所以测试全绿而真实事件纹丝不动——测试没有覆盖作者数据的真实写法，这是我的测试设计失误。

实测证据：修复前 `译后=gettarget(x_copy)/d`、`eval(x_copy=3,d=6)=-99`（执行失败默认）；修复后 `译后=x_copy/d`、`eval=0.5` ✓。

## 修复

1. **正则扩为词字符**：gettarget/getchara 参数捕获 `[a-z]+`/`[xydapn]{1,6}` → `[A-Za-z_0-9]+`（顺带修掉 `getchara(normal)` 的 o 不在字符类的同类地雷）；未知名**透传**（未注册名编译期可见报错，替代原先静默映射成 self_x 的错误值行为）。
2. **参数族补全**：`gettarget(dm_apfrepul/dm_situate/dm_smn/dm_sms)` → 目标角色态势结果快照（map_force/sit_mean/Smn/Sms，EXPR_VARS 注册+快照填充）；`gettarget(1d_ht_aver)` 型数字开头态势变量 → 重排翻译为合法标识符 `ht1daver`。
3. **加载警告**：官方事件表加载时编译失败不再静默（push_warning 带事件名与错误）——静默是本次事故能藏两周的原因。
4. **回归断言**：smoke 新增 [15] 七断言（真实 `gettarget(x_copy)` 翻译/执行、getchara(normal)、dm_smn、1d_ht_aver 重排、Youshio1 本体编译零错+帧控激活）。
