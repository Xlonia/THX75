# 弹幕旋转重复 + 运行时变量语义修订 实现报告（2026-10-15）

**依据**：作者在 `scheme/东方无欲拾食纪-弹幕编辑器-新.txt` 中的三处修订：
①新增"通用弹幕旋转重复参数"整节（rotate_range/div/rate/offset/sequence/pingpong/delay + rotate_id，目的=单事件实现道中弧形/扇形/"之"字形弹幕）；
②"选取——(火炮/无人机)"移入通用弹幕重复参数组；
③"弹幕自变量"改名"弹幕在运行时返回的变量"（t/rate_roll/pattern_roll 只读可引用、不可设定）；
④repeat_time 语义由"出现后的持续时间"改为"重新释放一个副本重复时间"（间隔）。

**全部落地并验证**：smoke 新增 18 条旋转重复断言全过（SMOKE_OK），编辑器场景加载无解析错误，tick 性能复测无回归。

## 一、数据层（danmaku_event_data.gd）

- CSV 表头 47→**54 列**，rotate_* 7 列**尾部追加**（教训在案：新列禁止中段插入，旧 47 列文件解析时缺列自动取默认值=旋转关闭，完全兼容）。
- `rotate_sequence` 合法值 `cw/ccw/mid_sync/mid_left/mid_right`（顺时针/逆时针/中间同时/中间先后左/中间先后右），非法值回退 cw。
- `rotate_pingpong` 解析容忍布尔 `true`=1.0（作者消歧义设计：布尔真→1→每 id 反序）；数值运行时去尾。
- **repeat_time 字段注释同步改为"副本重复间隔"**。
- 新增纯静态数学（无副作用，战场/预览/smoke 三方共用）：
  - `rotate_positions(ev)`：角度副本位置。D=0→仅原方向；range≥π→全圆 D 点从 0° 起分（首尾不重复）；其余→D 等分 D+1 条边缘（-range/2…+range/2）。
  - `rotate_steps(ev)`：释放步序，每步=同时释放的 [位置序号, rotate_id] 列表。中间系：中线副本 id=0，向两侧配对，**左侧先编号**（解决奇数等分无中线副本的编号，作者原文）；cw=左缘 id0 顺数；ccw=右缘 id0 逆数。
  - `rotate_release_plan(ev)`：rotate_rate>0 时按步序循环释放至 rate 次；**回弹=下一步 id 命中基数的非零倍数时反序剩余步序**（先发者不变）——与文档算例吻合：D=8、基数5 → 释放序 012348765（文档 123459876）。

## 二、运行时（bullet_runtime.gd / fire_control.gd / battle_arena.gd）

- Bullet 新增 `rot_angle`（本副本轨迹整体旋转角，含 rotate_offset）与 `rotate_id`。**必须在 setup 前写入**（冻结表达式在 setup 内求值，`rotate_id` 才可见）。
- 旋转应用按弹型：一般类（冻结初态+非冻结逐帧 dir）/物理类（velocity 向量）/轨道类（坐标系 x 轴，y 随之）/瞬时类（采样几何绕原点旋转+AABB 修正，动态重建后重旋）/点向类（初始朝向偏转，后续仍自寻的）。
- **rotate_id / rate_roll / pattern_roll 入表达式 ctx**（只读运行时变量）：`speed="rotate_id*2"` 等写法即刻可用（smoke 实证）。
- 发射链：`fired` 信号增携 rolls（发射骰/规律累加值随事件传出）→ `_spawn_event_copies` 按 release_plan 展开；`rotate_delay>0` 的后续步走 `_rot_pend` 延时队列（**从火力点实时位置出发**），同帧步立即出膛。
- repeat 整扇重放：旋转事件的 repeat 节拍只挂在首个副本（防 N 倍繁殖——沿用冻结元凶教训），补发时重放整扇（子代不再携带节拍）。
- **火炮（is_cannon）**：勾选后事件不再自主发射——登记为炮节点，按 repeat_time 间隔、repeat_freq 拍数生成**repeat 禁用**的弹幕粒子（文档原文语义），拍数尽自毁；上限 64 节点防失控。无人机（不勾）=现行自主发射。
- **repeat_time 语义修订**：第 n 次补发发生于 `n×repeat_time` 帧（repeat_freq=补发次数）。⚠️ 作者注意：旧数据若按原"持续时间"语义调参，表现会改变（例：repeat_time=60/repeat_freq=2 由"60帧内补2发"变为"第60、120帧各补1发"）。

## 三、编辑器（danmaku_editor.gd / danmaku_preview_stage.gd）

- 通用参数面板：重复组改为 `重复时间(帧,副本间隔)/重复频率(补发次数)/选取：火炮(勾选)/无人机(不勾)`，其下新增旋转重复 8 项（时序下拉用枚举值+标签注明，与其余枚举字段同风格）。
- 参数引入工具新增**"运行时返回变量"类目**：t/t_r/rate_roll/pattern_roll/rotate_id/r0/r1/n/wpcs/to_c/main_lr/sub_lr，单击提示"只读、可直接引用、不可手动设定"，插入裸变量名（变量引用类 gettarget 等维持 `sys(参数)` 格式）。
- 弹幕显示浮窗：**半透明扇形+分割点实时预览**（默认朝右=角度偏差投射，作者原文口径；range≥π 画全圆），Z 发射同样走旋转展开（含步序延时）。

## 四、文档数字口径的两处实现判定（请作者复核）

1. **中间系步数**：mid_sync/先后左右按"步"延时（同数字并列的两侧同帧），D=8 时为 5 步 9 副本、D=3 时为 2 步 4 副本——rotate_delay 计的是"步间隔"而非"单副本间隔"。
2. **回弹基数=2 的释放序**：文档例"125698743"按我方"命中倍数→反序剩余"规则推不出（怀疑笔误）；基数=5 的例子可完全复现，故按该规则实现（基数1=全反序锯齿）。
