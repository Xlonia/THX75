# 旋转重复歧义修复批报告（2026-10-19）

**依据**：作者五点批复——①repeat 与 rotate 相乘独立、预览路径仅单弹不可接受；②首弹不得随外界时序偏转（顺时针自逆时针极点/逆时针反之/中间系自中线起——与现有步序一致，问题出在基向漂移）；③rotate 五参数数据类型表达式化；④预览假想目标=光标位置；⑤弹幕事件表单移除火力点参数。

**全部落地**：SMOKE_OK（旋转段扩至 26 断言，含对战发射链路/延时锚定/repeat×rotate 相乘实证），编辑器加载无解析错误，tick 性能复测 PASS 无回归。

## 一、预览仅单弹的根因与修复

- **试炼场预览**：`_preview_emitter` 原先直接 `_spawn_bullet`，**绕过旋转展开**——即根因。已改走 `_spawn_event_copies`（扇形+延时步序+repeat 相乘全链路）。
- **自定义对战**：发射链路（`_on_fire`→扇形展开）经 headless 实测是通的（smoke 对战链路段：首发+4 延时+repeat 整扇重放全过）。若作者仍见单弹，请确认测试事件已**导出**进对战读取的 CSV（编辑器工作集与对战数据是两套存储；试炼场预览经 `_find_event` 优先读编辑器工作集，自定义对战读官方 CSV）。
- repeat×rotate 语义确认实现正确：repeat 的节拍挂在扇形**首个副本**（防 N 倍繁殖），每次补发**整扇重放**——"repeat 两次 = 旋转副本整体再重复两次"。

## 二、首弹锚定（基向漂移修复）

漂移机理：带 rotate_delay 的副本逐个出膛时，自机狙/表达式基向在**各自出膛时刻**重新解算，目标移动导致整扇角度涂抹不规则。

修复：**首发副本即锚**——其最终方向反解出"扇形基向"（`base = dir.rotated(-本副本角)`），延时副本带 `pinned_dir` 出膛（`dir = base.rotated(槽位角)`），覆盖 gettarget 快照与自动瞄准。释放顺序保持：cw=左缘（逆时针极点）→ 顺时针、ccw=右缘、中间系=中线先——与批复要求一致。范围：仅一般类（弧形弹主力）；物理/轨道/点向类的延时副本仍按各自表达式（报告中说明）。

## 三、rotate 参数表达式化（类型批复落地）

| 参数 | 类型 | 实现 |
|---|---|---|
| rotate_range / rotate_offset | 浮点式 | 字符串列存原文→`DanmakuExpr` 编译→释放时求值 |
| rotate_div / rotate_rate | 整式 | 同上，求值后 `int(floor(·))`，负值钳 0 |
| rotate_pingpong | 式/命题 | 数字取整；命题求值即 0/1 浮点，取整同义；旧 CSV 的 `true` 容错为 "1" |
| rotate_delay | 普通整数（帧） | 未列入表达式化清单，保持 |

- 与弹幕运行表达式同体系：单个数字=常量式，支持局部/外部变量；**释放时刻求值一次**（`eval_rotate_params`），上下文含 field_t/phase、火力点 wpcs/to_c/lr、self 系、目标快照（与弹幕出现同语义）。
- 静态数学（positions/steps/release_plan）改收求值结果字典 `rp`，战场/预览/smoke 三方共用。
- 编辑器五个字段改 **expr 控件**（带参/运按钮），标签注明类型。
- repeat 整扇重放的判定改为"rotate_div 原文非 '0' 即按旋转事件"（表达式化后的兼容判断）。
